# Treino_ransonware_DIO

## Lab criação de um ransomware me python

Foi criado um arquivo em python para encriptar e outro para desincriptar ( encrypter.py e decrypter.py) para utilizar no arquivo "teste.txt". 

Ao executar o encrypt.py ele transforma o teste.txt em teste.txt.ransomwaresacana encripatando todo seu conteúdo. E com o decrypt.py desfaz o procedimento anterior.
